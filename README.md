# PID_Study — 江协科技 PID 算法与倒立摆教学实践

本项目是基于**江协科技（江科大）**的 PID 控制系列视频教程，结合电机及小车倒立摆硬件进行算法编写、参数整定和控制方案优化的实践学习工程。

---

## 🧭 PID 学习与算法优化路线

整个项目共包含 17 个递进式的实验，全面覆盖了从最基础的 PID 单环控制，到针对工程难题的各种高级优化方案，再到复杂的多环串级控制以及自动启摆控制：

### 🎯 第一阶段：PID 基础与单环控制
本阶段主要完成底层硬件驱动，并在控速和定位场景中实现最经典的位置式与增量式 PID。
*   📂 [00-PID综合测试程序](file:///E:/Project/PID_Study/00-PID综合测试程序)：集成了多项控制模式与调试参数的综合演示源码。
*   📂 [01-基础驱动代码](file:///E:/Project/PID_Study/01-基础驱动代码)：实现电机（PWM）、编码器（测速）以及 OLED 屏幕等外设的底层配置。
*   📂 [02-位置式PID定速控制](file:///E:/Project/PID_Study/02-位置式PID定速控制)：使用经典位置式 PID 进行电机恒速控制，体验比例和积分项的作用。
*   📂 [03-增量式PID定速控制](file:///E:/Project/PID_Study/03-增量式PID定速控制)：利用增量式 PID 驱动电机速度，体会其无需历史累加、不易饱和的基因优势。
*   📂 [04-位置式PID定位置控制](file:///E:/Project/PID_Study/04-位置式PID定位置控制)：实现电机旋转角度的精准定位，观察定位置控制中的“超调”与“抖振”。
*   📂 [05-增量式PID定位置控制](file:///E:/Project/PID_Study/05-增量式PID定位置控制)：基于增量式 PID 算法实现目标位置控制。

---

### 🚀 第二阶段：位置式 PID 的高级优化方案
针对“位置式 PID 定位置控制”在物理场景下面临的超调、机械静摩擦、微分冲击及噪声抖动等问题，依次实践 6 种优化“补丁”：
*   📂 [06-位置式PID定速控制-积分限幅](file:///E:/Project/PID_Study/06-位置式PID定速控制-积分限幅)：限制积分项的累加最大值，防止启动或大阶跃响应时的积分饱和（Anti-Windup）。
*   📂 [07-位置式PID定位置控制-积分分离](file:///E:/Project/PID_Study/07-位置式PID定位置控制-积分分离)：在大误差时暂时切断积分项，只在偏差较小时引入积分，消除启动阶段累积的超调。
*   📂 [08-位置式PID定位置控制-变速积分](file:///E:/Project/PID_Study/08-位置式PID定位置控制-变速积分)：根据当前误差大小动态缩放积分累加系数，兼顾响应的快速性与平稳性。
*   📂 [09-位置式PID定位置控制-微分先行](file:///E:/Project/PID_Study/09-位置式PID定位置控制-微分先行)：微分项只对“测量实际反馈”求导而非对“误差”求导，彻底消除由于目标突变引起的微分冲击。
*   📂 [10-位置式PID定位置控制-不完全微分](file:///E:/Project/PID_Study/10-位置式PID定位置控制-不完全微分)：在微分环路中串联低通滤波器，过滤掉传感器高频噪点带来的控制输出毛刺。
*   📂 [11-位置式PID定位置控制-输出偏移-输入死区](file:///E:/Project/PID_Study/11-位置式PID定位置控制-输出偏移-输入死区)：
    *   **输出偏移（Bias）**：输出端直接叠加偏置，用于克服传动机构起步时的**静摩擦力**死区。
    *   **输入死区（Dead Zone）**：微小误差强制置零，防止小车在终点附近因传感器波动和微小偏差产生高频来回抽搐（抖振）。

### 🎡 第三阶段：多环串级控制与倒立摆硬件实战
从单环拓展到多环，并在具有高阶不稳定特性的倒立摆（Inverted Pendulum）上实现平衡与自适应控制。
*   📂 [12-双环PID定速定位置控制](file:///E:/Project/PID_Study/12-双环PID定速定位置控制)：位置环（外环）计算出期望速度，速度环（内环）根据期望值快速跟踪。外环控位置，内环限速度，实现平滑、无超调的极佳定位效果。
*   📂 [13-双环PID定速定位置控制-代码封装](file:///E:/Project/PID_Study/13-双环PID定速定位置控制-代码封装)：对多环参数、输入输出状态进行 C 语言结构体与模块化函数封装，提升工程代码的可移植性。
*   📂 [14-基础驱动代码-角度传感器](file:///E:/Project/PID_Study/14-基础驱动代码-角度传感器)：增加旋转电位器/角度传感器的 ADC 驱动代码，用于感知摆杆所处的精确偏角。
*   📂 [15-倒立摆](file:///E:/Project/PID_Study/15-倒立摆)：基于双环串级 PID 算法（内环控制角度，外环调整小车位置），实现摆杆在直立区间的稳态平衡控制。
*   📂 [16-倒立摆-自动启摆](file:///E:/Project/PID_Study/16-倒立摆-自动启摆)：结合“能量注入法”，检测摆杆在摆动轨迹上的左右最高点，通过顺势和反向脉冲给小车施加突变驱动力累积能量，让摆杆由下垂状态自动摇晃荡起，并最终在直立瞬间由 PID 捕获稳态接管。
