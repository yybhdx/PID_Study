# 深入理解 PID 控制中的“不完全微分”

> 本文档记录了关于位置式 PID 控制中“不完全微分”算法的核心疑问与原理解答。

---

## ❓ 问题一：启用不完全微分的目的

> **Q：之所以要启用不完全微分，是为了要尽可能消除噪声对 D 项的干扰是吗？**

**答：是的，您的理解完全正确！**

在标准的 PID 控制中，**微分项（D 项）**的作用是根据“误差的变化率”来提前介入控制，也就是具有“预测”作用。在数字控制系统中，微分项通常通过计算两次相邻误差的差值来获得：
```c
Dif = Kd * (Error0 - Error1)
```

然而，在实际的物理系统中（例如编码器读取、电机控制），不可避免地会存在各种**高频噪声**（比如传感器数据跳动、电磁干扰等）。

- 🚨 **纯微分的缺陷**：纯微分操作对高频信号极其敏感。即使是微小的噪声抖动，在求差值时也会被急剧放大，导致微分项输出一个非常大且剧烈波动的控制量。这会使执行机构（比如电机）出现剧烈抖动、发热，甚至导致系统无法稳定。
- 🛡️ **不完全微分的优势**：为了解决上述问题，我们通常会采用**不完全微分**。它的本质是在微分项后面串联了一个**一阶低通滤波器**。代码中的实现为：
  ```c
  DifOut = (1 - a) * Kd * (Error0 - Error1) + a * DifOut;
  ```

### 主要作用总结
1. **滤除高频噪声**：通过和上一次的微分输出进行加权平均（滤波系数 `a` 控制平滑程度），把那些瞬间突变的噪声毛刺过滤掉。
2. **保留有效趋势**：保留了系统真实的、低频的误差变化趋势，使得微分项依然能够发挥“预测”的作用。

**结论**：引入不完全微分就是为了在保留微分项“超前调节”功能的同时，有效滤除高频噪声对控制系统的干扰，使得输出更加平滑稳定。

## ❓ 问题二：低通滤波代码原理解析

> **Q：代码中是这样写的，为什么这样可以实现不完全微分（低通滤波）？请详细讲解一下。**
> ```c
> float a = 0.9;
> DifOut = (1 - a) * Kd * (Error0 - Error1) + a * DifOut;
> ```

**答：** 这段代码实际上实现了一个**一阶低通滤波器**（在离散算法中也常称为“指数平滑法”或 EMA）。在工程应用上，“不完全微分”就是指“纯微分”加上“低通滤波”。

为了方便理解，我们将公式拆解如下：

| 变量 / 代码片段 | 含义说明 |
| :--- | :--- |
| **`Kd * (Error0 - Error1)`** | 本次计算出的**纯微分值**（原始的、未经处理的微分，包含噪声）。我们称之为 `D_raw`。 |
| **等号右边的 `DifOut`** | **上一次的微分输出值**（历史平滑值）。我们称之为 `D_prev`。 |
| **等号左边的 `DifOut`** | **本次最终的微分输出值**。我们称之为 `D_new`。 |
| **`a`** | **滤波系数**，取值范围是 0 到 1 之间（此处代码取 0.9）。 |

所以，公式可以抽象为：
> **`本次输出 = (1 - a) * 本次原始值 + a * 上次输出`**

### 为什么它能抗噪（滤波）？

我们可以通过两种极端情况来直观理解这个公式的作用：

#### 1. 当 `a` 接近 0 时（例如 `a = 0`）
公式变为：
> `本次输出 = 1 * 本次原始值 + 0 * 上次输出 = 本次原始值`

这时它就退化成了**纯微分（完全微分）**。任何高频噪声都会被 100% 毫无保留地输出，没有任何抗噪能力。

#### 2. 当 `a` 比较大时（例如代码中的 `a = 0.9`）

公式变为：
> `本次输出 = 0.1 * 本次原始值 + 0.9 * 上次输出`

这意味着，本次最新的输出，**只有 10% 相信当前计算出的原始微分值，而有 90% 依赖于历史平滑值**。

- 📉 **面对高频噪声（突变）**：如果当前遇到一个极大的高频噪声干扰，导致 `本次原始值` 瞬间变得极大，但因为它要乘以 `0.1`，这个突变被**极大地削弱了**。系统输出不会跟着发生剧烈抖动，这就实现了“抗噪”。
- 📈 **面对有效信号（低频趋势）**：如果误差是真实且持续在改变的，那么 `本次原始值` 就会**一直稳定在一个数值附近**。随着时间的推移，哪怕每次只取 10%，`本次输出` 也会慢慢累加并逼近真实的微分值，从而保留了微分的“预测”趋势。

### 核心总结

这句代码通过**给历史数据和当前数据分配不同的权重**：

- 过滤掉了那些瞬间产生、瞬间消失的“高频噪声毛刺”；
- 让那些持续存在的“低频真实信号”平滑地通过。

这就是一阶低通滤波的原理，也是“不完全微分”能够稳定系统的核心所在。

## ❓ 问题三：深入理解“慢慢累加并逼近真实的微分值”

> **Q：在问题二中提到：“如果误差是真实且持续在改变的，那么 `本次原始值` 就会一直稳定在一个数值附近。随着时间的推移，哪怕每次只取 10%，`本次输出` 也会慢慢累加并逼近真实的微分值”。**
> **这句话具体该如何理解？为什么输出会慢慢累加并逼近真实的微分值？**

**答：**

为了让你秒懂这句话，我们可以通过一个具体的数据推演来观察公式的运行过程。

公式回顾：
`本次最终输出 = (0.9 * 上次输出) + (0.1 * 本次原始微分值)`

#### 1. 为什么“原始微分值会稳定在一个数值附近”？

你要记住，微分算的是**“变化率（也就是差值）”**。
假设你的电机正在**非常平稳、匀速地**靠近目标：
*   第1次，距离差了 50
*   第2次，距离差了 40 （两次差值是 **10**）
*   第3次，距离差了 30 （两次差值是 **10**）
*   第4次，距离差了 20 （两次差值是 **10**）

你看，虽然“误差”在一直变小，但是由于你是匀速靠近的，误差的“变化率（原始微分值）”却一直**死死地稳定在 10 附近**。
只要系统真正在平稳运动，这个微分值就会持续、稳定地存在。这就是所谓的**“有效信号（低频趋势）”**。

#### 2. 为什么会“慢慢累加并逼近”？（数据推演）

假设现在电机的真实状态就像上面那样，微分的“本次原始值”一直稳定地输出 **100**。
我们来看看公式是怎么工作的 *(假设最开始系统静止，上次输出是 0)*：

*   **第 1 次计算**：
    `本次输出 = (0.9 * 0) + (0.1 * 100) = 0 + 10 = 10`
    *(现在最终输出只有 10，离真实的 100 还差得远)*

*   **第 2 次计算**：（注意，上次的输出变成了 10）
    `本次输出 = (0.9 * 10) + (0.1 * 100) = 9 + 10 = 19`
    *(输出涨到了 19，正在靠近 100)*

*   **第 3 次计算**：（上次的输出变成了 19）
    `本次输出 = (0.9 * 19) + (0.1 * 100) = 17.1 + 10 = 27.1`

*   **第 4 次计算**：
    `本次输出 = (0.9 * 27.1) + (0.1 * 100) = 24.39 + 10 = 34.39`

……
规律非常明显：**只要这个 `100`（真实趋势）持续存在的时间足够长，最终的输出值就会像爬楼梯一样：`10 -> 19 -> 27 -> 34 -> ... -> 80 -> 90 -> 99.9`。**
它最终会**无限逼近真实的 100**。

#### 3. 终极感悟：为什么非要“慢慢爬”？

直接给 100 不行吗？为什么非要这样慢慢爬楼梯？
**答案是：为了防干扰（防噪声）！**

假设传感器被电磁干扰，爆出了一个极离谱的错误信号：**原始微分值瞬间飙升到了 1000！但这只是个干扰，下一秒立马恢复成 0。**
*   如果不用滤波，电机瞬间输出 1000，可能直接过载损坏。
*   如果用滤波（每次只信 10%）：
    *   干扰来的那 1 次：`输出 = 0.9*0 + 0.1*1000 = 100`。
    *   下 1 次（干扰消失，原始值归 0）：`输出 = 0.9*100 + 0.1*0 = 90`。
    *   再下 1 次：`81` -> `72` -> `64` ... 迅速衰减归零。

对于**瞬间的高频干扰（只出现一次）**，它只取了 10%，根本没机会爬到 1000，就把尖峰硬生生削平了。
而对于**真实的有效信号（一直存在）**，它就有足够的时间，一步步慢慢爬上去，最终还原系统需要的真实阻尼力！

这就是**“拦截高频噪声，放行低频趋势”**的神奇所在。
