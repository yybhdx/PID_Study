# STM32 旋转倒立摆 —— 自动启摆与串级 PID 平衡控制系统

> 参考教程：[江协科技 - PID入门教程 电机控制 倒立摆 全程手把手打代码调试](https://www.bilibili.com/video/BV1G9zdYQEr3/)

本项目是基于 **STM32F103C8T6** 微控制器设计的**一级旋转倒立摆**控制系统。系统集成了能量累积自动启摆状态机、双环串级 PID 平衡控制（外环位置+内环角度）、防冲击状态平滑切换、OLED 参数实时显示及电位器在线参数整定功能。

## 🔩 硬件结构

本系统为**旋转式一级倒立摆**，机械结构模型如下：

```
        摆杆（被动臂，自由旋转）
         │
    ─────┼───── 横杆（主动臂，由电机驱动旋转）
         │
       铰接点（带有角度传感器）
         │
     ┌───┴───┐
     │ 电 机 │   ← 直流电机通过传动机构驱动横杆旋转
     └───────┘
```

* **横杆（主动臂）**：由直流电机驱动，可正反双向旋转。通过编码器测量其旋转角度与位移。
* **摆杆（被动臂）**：铰接于横杆末端，可自由摆动。采用电位器式角度传感器测量其相对垂直方向的偏角。

## ⚙️ 控制算法架构

系统采用 **双环串级 PID（位置式 PID）** 控制，在 `TIM1_UP_IRQHandler`（1ms 定时中断）中进行分频调度：

```
  目标位置 ──→ [外环 位置PID 50ms] ──→ 角度修正量
                      ↑                      │
              横杆实际位移                     ↓
               (编码器)           CENTER_ANGLE - 修正量
                                             │
                                             ↓
                                   [内环 角度PID 5ms] ──→ 电机PWM
                                         ↑
                                   摆杆实际角度
                                    (ADC传感器)
```

### 1. 内环：角度控制环 (`AngePid`)
* **反馈量**：摆杆角度 `Angle`（ADC 读数，垂直平衡点约 `2048`）。
* **控制周期**：**5ms**（快速响应，实时救摆）。
* **PID 参数**：`Kp = 0.2`, `Ki = 0.01`, `Kd = 0.4`, 输出限幅 `±100`。

### 2. 外环：位置控制环 (`LocationPid`)
* **反馈量**：横杆旋转累计位移 `Location`（编码器速度积分）。
* **控制周期**：**50ms**（周期约为内环 10 倍，防止双环打架发散）。
* **PID 参数**：`Kp = 0.4`, `Ki = 0.01`, `Kd = 4.0`, 输出限幅 `±100`。

### 3. 串级耦合极性关系
```c
AngePid.Target = CENTER_ANGLE - LocationPid.Out;
```
> **注意**：此处必须使用 **`-` 减号** 链接外环与内环。若横杆偏右，外环产生修正量，减法拉低内环目标角度，引导摆杆向左倾斜；内环为拯救摆杆向左加速，从而将横杆顺势带回起点，构成**负反馈闭环**。

## 🐛 常见工程问题与优化方案 (Troubleshooting & Optimizations)

在倒立摆系统的实际调试过程中，存在以下 3 个极具代表性的工程问题及其优化解法：

### 1. 启动前摆杆底部死区/盲区误判问题

* **问题现象**：
  在程序未启动前，摆杆长时间自然悬挂在下方（180°倒悬状态）。由于电位器式传感器或机械结构的读数特性，在底部盲区时 ADC 采集到的角度值可能刚好在 `2048` 附近（或者为任意随机读数）。如果直接启动启摆极点检测，系统可能会误认为摆杆已经直立，从而直接错误切入 PID 控制。
* **原因分析**：
  摆杆静止在底部盲区时速度为 0，角度传感器静态读数容易干扰启动判断。
* **优化解法代码**：
  在按键 K1 的处理逻辑中，**按下 K1 后直接强制切入 `RunState = 21`**（向左顺势推摆一次），使摆杆立刻获得初始动能摆离底部盲区；同时保证在任何其他运行状态下按下 K1，都能随时安全停止。
  ```c
  if (key_num == 1)
  {
      if (RunState == 0)
      {
          RunState = 21; // 按下 K1 立刻先主动摆动 1 次，强制让摆杆离开底部盲区
      }
      else
      {
          RunState = 0;  // 在任何其他运行状态下按下 K1，均可随时回到停止状态
      }
  }
  ```

---

### 2. 起摆成功后位置突变与机械冲倒问题

* **问题现象**：
  在启动程序前，如果人为将横杆转到了偏离起点很远的位置（例如 OLED 显示 `Location = +800`）。此时按 K1 起摆，一旦摆杆在远端成功甩到顶部并切入 PID 平衡控制，小车就会因位置环存在巨大初始误差，瞬间以极高速度机械地“猛冲回 0 位置”，导致体验极差且极易冲倒跌落。
* **原因分析**：
  起摆成功时的实际位置与设定的目标位置 `0` 存在较大差距，导致外环产生巨大的初始阶跃控制量。
* **优化解法代码**：
  在摆杆成功到达顶部中心控制区并切入 `RunState = 4` 的瞬间，**将当前实际位置归零（`Location = 0`）**。规定起摆成功的瞬间位置即为新的 `0` 位置基准。
  ```c
  if (Angle0 > CENTER_ANGLE - CENTER_RANGE && Angle0 < CENTER_ANGLE + CENTER_RANGE &&
      Angle1 > CENTER_ANGLE - CENTER_RANGE && Angle1 < CENTER_ANGLE + CENTER_RANGE)
  {
      Location = 0;  // 在起摆成功的瞬间将实际位置清零，重新设定起点基准
      RunState = 4;  // 切入 PID 控制
  }
  ```

---

### 3. PID 历史残余积分过爆导致的“抽风”与无法起摆问题

* **问题现象**：
  系统运行一段时间后或多次起摆失败后，再次启动时发现**摆杆无论如何都无法成功起摆**；即便偶然荡到了顶端，一切入平衡状态立刻被一股巨大的推力猛烈甩飞（出现“抽风”现象），且后续抖动越来越大。必须按一次单片机复位键（Reset）才能恢复正常。
* **原因分析**：
  摆杆在下倒或多次起摆的过程中，PID 控制器一直在运行并不断累加偏差，导致角度环积分项 `AngePid.ErrorInt` 和位置环积分项 `LocationPid.ErrorInt` 积累了极大的历史误差积分值。一旦切入 PID 控制，这个巨大的残余积分力会瞬间施加给电机，直接破坏平衡。
* **优化解法代码**：
  在每次切入 `RunState = 4` 倒立摆平衡控制的时刻，**强制清理角度环与位置环的误差积分项**（`ErrorInt = 0`）。
  ```c
  if (Angle0 > CENTER_ANGLE - CENTER_RANGE && Angle0 < CENTER_ANGLE + CENTER_RANGE &&
      Angle1 > CENTER_ANGLE - CENTER_RANGE && Angle1 < CENTER_ANGLE + CENTER_RANGE)
  {
      Location = 0;              // 位置基准归零
      AngePid.ErrorInt = 0;      // 强制清空角度环误差积分，防止历史残余积分甩飞摆杆
      LocationPid.ErrorInt = 0;  // 强制清空位置环误差积分，消除启动初始抽风问题
      RunState = 4;              // 切入 PID 控制
  }
  ```
  > **控制工程规律**：任何带积分项（Ki > 0）的 PID 控制器在启动、切换状态或复位时，**都必须先清零误差积分**，避免初始历史积分过爆导致控制失控。

## 🎮 按键交互功能

| 按键 | 引脚 | 核心功能与运行逻辑 |
| :---: | :---: | :--- |
| **KEY1** | PB10 | **系统启停 / 主动脱离死区**：<br>• 在任何运行状态下按下，立刻切换为 `RunState = 0`（停机）。<br>• 在停机状态下按下，直接切入 `RunState = 21` 强行摆动一次，**使摆杆迅速脱离底部自然悬挂死区**并开启自动起摆流程。 |
| **KEY2** | PB11 | **目标位置正向偏移**：外环目标位置 `LocationPid.Target += 408`（向右微调约编码器转动一圈，最大限制 +4080）。 |
| **KEY3** | PA11 | **目标位置负向偏移**：外环目标位置 `LocationPid.Target -= 408`（向左微调约编码器转动一圈，最小限制 -4080）。 |
| **KEY4** | PA12 | 预留拓展功能接口。 |

## 🖥️ OLED 屏幕显示说明

OLED 显示屏使用格式化控制字符串（如 `%05.3f`, `%+05d`, `%+04.0f` 等），严格规定每个变量的**显示宽度、补零和正负号**，防止屏幕刷屏残影和文本对齐跳动。

屏幕布局分为左右两列：

```
RunState: 01
Angle              Location
kp:0.200           kp:0.400
ki:0.010           ki:0.010
kd:0.400           kd:4.000
Tar:2048           Tar:+0000
Act:2048           Act:+0000
Out:+000           Out:+000
```
